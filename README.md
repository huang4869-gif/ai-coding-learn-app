# AI 编程随身学（里程碑一：静态原型）

这是「AI 编程随身学」的第一版静态网页原型。**纯网页，无需后端、无需安装任何东西**，双击就能看。

## 这里面有什么

- 4 个页面：**今日 / 课程 / 收藏 / 我的**
- 6 大模块 24 节课的目录（第 1 节《什么是 AI 编程？》已有完整内容，含 3 道小测验）
- 音频播放器（配音还没生成，会显示“即将上线”，属正常）
- 学习进度、收藏：**自动存在你这台设备的浏览器里**

## 怎么在电脑上看

直接**双击 `index.html`** 就能用浏览器打开。

> 小提示：用“双击打开”时，浏览器对音频文件的处理较严格；如果想更接近真机效果，可以让我帮你“起一个本地预览服务”再看。

## 怎么发到 iPhone 上（以后这一步）

把整个 `ai-coding-learn-app` 文件夹部署到任意免费托管平台（**Vercel / Netlify / GitHub Pages**），会得到一个网址；用 iPhone 的 Safari 打开那个网址即可。还能在 Safari 里「分享 → 添加到主屏幕」，像 App 一样使用。

## 怎么加配音（音频）

1. 用 AI 配音工具，把每节课的文字生成 mp3（流程见产品文档 v0.2 第 12 节）。
2. 文件按 `模块-课号` 命名，例如第 1 节就是 **`m1-l1.mp3`**，放进 `audio/` 文件夹。
3. 命名规则要和 `js/data.js` 里每节课的 `audio` 字段一致，放进去就能播。

## 怎么加 / 改课程内容

所有课程内容都在 **`js/data.js`** 里。照着第 1 节（`l1`）的写法，把第 2~24 节的
`oneLine`（一句话解释）、`body`（正文）、`example`（例子）、`keypoints`（重点）、
`pitfalls`（误区）、`quiz`（测验）填上，并把 `ready` 改成 `true`，课程就会“解锁”。

## 文件结构

```
ai-coding-learn-app/
├─ index.html        手机外壳 + 底部标签栏
├─ css/styles.css    “温暖友好”设计系统（改颜色/样式在这里）
├─ js/data.js        课程内容仓库（加课/改课在这里）
├─ js/app.js         页面切换、音频、测验、本机进度
├─ audio/            放 AI 配音 mp3（命名如 m1-l1.mp3）
└─ README.md         本说明
```
